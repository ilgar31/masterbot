# Чат-бот клиники

Минимальный бот для регистрации/входа по телефону, просмотра подписки и подключения абонемента через уже написанное API клиники. Запись на прием, эквайринг и внешняя CRM-интеграция в этом проекте не используются.

## Что реализовано

- согласие на обработку ПДн из отдельного файла `consent.txt`;
- регистрация и повторный вход по номеру телефона;
- запрос подписки клиента через `GET /clients/{id}/subscription/`;
- список абонементов через `GET /subscriptions/`;
- подключение абонемента через `POST /clients/{id}/subscription/`;
- VK Callback API адаптер без сторонних бот-библиотек;
- простая SQLite-база для состояний, согласий, контента и заявок;
- веб-админка для акций, правил рекомендаций, магазина бонусов и шаблонов уведомлений.

## Запуск

1. Установите зависимости:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

2. Создайте переменные окружения по примеру `.env.example`.

3. Запустите VK Callback сервер:

```powershell
.venv\Scripts\python.exe main.py --mode vk
```

Адрес для VK Callback API: `http://<host>:8080/vk/callback`.

4. Запустите админку отдельно:

```powershell
.venv\Scripts\python.exe main.py --mode admin
```

По умолчанию она доступна на `http://127.0.0.1:8081/`. Логин и пароль задаются через `ADMIN_LOGIN` и `ADMIN_PASSWORD`.

Можно запустить оба сервиса одной командой:

```powershell
.venv\Scripts\python.exe main.py --mode all
```

Для локальной проверки диалогов без VK:

```powershell
.venv\Scripts\python.exe main.py --mode cli
```

## Ожидаемые эндпоинты API

- `POST /clients/` - создание клиента. Бот отправляет `phone`, `full_name`, `name`, `email`. В ответе нужен `id` или `client_id`.
- `GET /clients/{id}` - получение клиента, зарезервировано для расширений.
- `PUT /clients/{id}` - обновление клиента, зарезервировано для расширений.
- `GET /subscriptions/` - список доступных абонементов.
- `POST /clients/{id}/subscription/` - подключение абонемента клиенту. Бот отправляет `subscription_id`.
- `GET /clients/{id}/subscription/` - данные о подписке клиента.
- `GET /prices/` и `GET /prices/{id}` - обертки в API-клиенте есть, в меню пока не выводятся.

## Админка

В админке можно редактировать:

- акции и скидки;
- описание правил рекомендаций;
- контакты поддержки;
- магазин товаров/услуг за бонусы;
- шаблоны уведомлений;
- смотреть заявки на списание бонусов.

Механика начисления бонусов и полноценная программа лояльности не реализованы намеренно: в боте есть только контент магазина и заявка на списание.
